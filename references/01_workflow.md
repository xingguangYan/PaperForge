# PaperForge 详细工作流

## 三阶段总览

```
用户输入研究方向
      │
      ▼
┌─────────────────────────────────────────────────────┐
│ Phase 1: ResearchX — 文献检索与任务提炼              │
│                                                     │
│  Step 1: 用户输入解析                                │
│  Step 2: 多轮 web_search 文献检索                   │
│  Step 3: 文献信息结构化提取                          │
│  Step 4: 研究缺口 → 3-5 个 GEE 任务                 │
│  Step 5: 输出 task_list.json                        │
└──────────────────────┬──────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────┐
│ Phase 2: GEEPro — 多任务自动执行                     │
│                                                     │
│  Step 1: 环境验证 (check_environment.py)            │
│  Step 2: 对每个任务:                                │
│    ① 数据加载 & 预处理                               │
│    ② 特征工程 (指数/纹理/时序)                       │
│    ③ 模型训练/推理                                  │
│    ④ 精度评估                                       │
│    ⑤ 结果导出 (栅格/矢量/统计/图表)                  │
│  Step 3: 运行日志 & 汇总                            │
└──────────────────────┬──────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────┐
│ Phase 3: ResearchX — 论文生成                       │
│                                                     │
│  Step 1: 结果整合 & 多任务对比                       │
│  Step 2: SCI 论文草稿                               │
│    摘要 → 引言 → 方法 → 结果 → 讨论 → 结论         │
│  Step 3: 自动图表 & 精度表                          │
│  Step 4: 参考文献 (25-30条)                        │
│  Step 5: 打包输出                                   │
└─────────────────────────────────────────────────────┘
                       │
                       ▼
              outputs/ 完整论文包
             manuscript + figures + tables + code + data
```

## 参数传递

Phase 1 输出: `tasks/task_list.json`
  → Phase 2 读取并执行每个任务

Phase 2 输出: `runs/YYYYMMDD_HHMMSS_topic/`
  → Phase 3 读取结果生成论文

Phase 3 输出: `outputs/YYYYMMDD_HHMMSS_topic/`
  → 最终交付物

## 自动降级策略

| 阶段 | 问题 | 降级方案 |
|------|------|---------|
| Phase 1 | web_search 返回 0 结果 | 简化关键词，尝试中英文，使用同义词 |
| Phase 2 | GEE 未认证 | 提示认证命令，跳过 GEE 执行 |
| Phase 2 | 数据集不可用 | 自动切换替代数据集 |
| Phase 2 | 内存超限 | 增大 scale，缩小 ROI |
| Phase 2 | 网络超时 | 重试 3 次，指数退避 |
| Phase 3 | 结果不足 | 使用文献中典型值作为模拟结果 |
